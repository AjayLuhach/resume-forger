How to share YOUR database with someone
  1. Atlas → Database Access → Add New Database User. Under privileges pick Custom Role and grant only find on <your db>.job_tracker. Never hand out the built-in read role: it exposes your users document, and with it your SMTP password and mail.
  2. Atlas → Network Access → add the friend's public IP.
  3. Send them the connection string for that user. When they paste it here, the Test button warns them if the credential can read more than it should.
